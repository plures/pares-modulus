# Pedantic

Pedantic brings DSC v3 compliance management into pares-radix. Validate configs, track drift over time, and enforce praxis-based guardrails with exportable compliance artifacts.

**Highlights**
- Compliance dashboard with KPI cards and trend charts
- Config browser with validation errors and execution plans
- Praxis rules + constraints to prevent risky deployments
- Export JUnit XML and SARIF JSON for pipeline integration
